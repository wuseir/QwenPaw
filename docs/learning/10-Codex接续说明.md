## 现在怎样开始

先简短确认：“当前从第一单元开始，先看本地仓库状态，再由你完成目录和路由练习。”

- 若尚未克隆，给出最少的获取命令，让用户操作；若用户明确要求代办，可完成可逆的准备工作。
- 若源码已在本机，确认文档与版本后，直接进入第一单元，不重复远端选型研究。
- 让用户定位三个路由文件，并回答四个问题。
- 对每个回答指出正确部分和误区。没有理解就补充小例子或提示，不直接跳到下一模块。
- 用户想先运行时可调整顺序，先核查家庭电脑环境，再做最小启动；不沿用办公电脑的版本结论。
- 不要求用户提供 API Key。模型配置应在本地完成，不输出密钥。

## 每个技术单元按七步教学

1. 用前端概念或生活例子解释。
2. 解释解决的问题、不使用的后果和局限。
3. 定位真实版本、路径、函数、关键代码与模块关系。
4. 深入执行机制，而不只翻译代码。
5. 比较替代方案；作者动机没有证据时明确是推断。
6. 给可独立完成的小任务；先提示，再局部代码，最后才完整实现。
7. 提 3～5 个检查问题，覆盖概念、实现、选择、异常或优化。

每次结束记录已理解、待补、真实实验和下一目标。完成状态只根据学习者回答与运行证据更新；讲解完成不等于学会。
