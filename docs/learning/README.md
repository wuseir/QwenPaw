## 回家后从这里开始

如果还没有本地副本，在你选择的父目录执行：

```powershell
git clone https://github.com/wuseir/QwenPaw.git
cd QwenPaw
git switch -c learning/round-1
```

学习分支从拉取后的当前提交创建，包含本目录文档。源码研究基线仍为 `45c754ee694c3e27ced3d27f8971449be067f534`，不是让你把分支切回该提交。

如果已经克隆过，先检查：

```powershell
git status -sb
git branch --show-current
git remote -v
```

仅当当前就在干净的 `main`，且 origin 指向本 fork 时，可以执行：

```powershell
git fetch origin
git merge --ff-only origin/main
```

有未提交改动、位于其他分支或出现分叉时，先让 Codex 查看状态并保留现场，再决定如何合入。不要用 reset、清理文件或强制推送来“同步”。
