## 回家后从这里开始

如果还没有本地副本，在你选择的父目录执行：

```powershell
git clone https://github.com/wuseir/QwenPaw.git
cd QwenPaw
git switch -c learning/round-1
```

学习分支从拉取后的当前提交创建，包含本目录文档。源码研究基线仍为 `45c754ee694c3e27ced3d27f8971449be067f534`，不是让你把分支切回该提交。

如果已经克隆过，先检查：

```powershell
git status -sb
git branch --show-current
git remote -v
```

若当前在干净的 `main` 或 `learning/round-1`，origin 指向本 fork，且当前分支提交是 `origin/main` 的祖先，可以快进同步：

```powershell
git fetch origin
git merge --ff-only origin/main
```

如果不确定祖先关系，先让 Codex 检查。有未提交改动、位于其他分支或出现分叉时，先让 Codex 查看状态并保留现场，再决定如何合入。不要用 reset、清理文件或强制推送来“同步”。

在家庭 Codex 打开仓库文件夹，发送：

> 请先读 AGENTS.md、docs/learning/08-知识盲区与复习计划.md 和 10-Codex接续说明.md。我已看过路由，并在 2026-10-30 完成启动，发送“你好”获得回应。沿用原来的 14 天计划，接着带我做 12-启动与请求追踪.md 中的 Network 请求练习。先检查家里的环境是否已就绪；如果能聊天，直接追踪请求。一次只推进一个单元，让我先操作和回答，再检查理解。
