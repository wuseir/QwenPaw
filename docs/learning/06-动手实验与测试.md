### 第一步：获取包含学习文档的源码

Fork 是 GitHub 上属于自己的仓库副本；Clone 是把仓库取到电脑；分支用于组织后续提交。

尚未克隆时，在自己选择的父目录执行：

```powershell
git clone https://github.com/wuseir/QwenPaw.git
cd QwenPaw
git switch -c learning/round-1
git status -sb
git log -1 --oneline
```

与此前聊天命令有一处有意调整：本次从最新拉取的提交创建学习分支，才能保留新增文档；不要在旧源码基线上新建分支而漏掉学习资料。基线 SHA 只用于源码对照。

若已经有本地副本，不重复 clone，不覆盖已有目录；先按 [README](README.md) 的同步说明检查并保留现场。已有学习分支时，也不重复创建同名分支。

家庭电脑路径自行选择，不默认存在办公电脑的盘符或工具。命令示例使用 Windows PowerShell；其他系统由 Codex 按实际环境调整。

### 第三步：亲自定位路由

用编辑器搜索，找到并记录：

1. `src/qwenpaw/app/_app.py` 中的 `app.include_router(api_router, prefix="/api")`。
2. `src/qwenpaw/app/routers/__init__.py` 中的 `router.include_router(console_router)`。
3. `src/qwenpaw/app/routers/console.py` 中的 `prefix="/console"`、`"/chat"` 和 `post_console_chat`。
4. `post_console_chat` 开头关于断连后继续运行的注释。

Vue Router 将地址对应到页面；后端路由将 HTTP 方法和地址对应到处理函数。先理解这种映射，不要求现在读懂完整异步函数。

定位依据：[固定版本控制台源码](https://github.com/wuseir/QwenPaw/blob/45c754ee694c3e27ced3d27f8971449be067f534/src/qwenpaw/app/routers/console.py)。
