# 核心技术知识地图

P0：直接影响核心链路，首轮必须掌握。P1：应理解设计和异常。P2：暂时了解边界即可。

以下是学习目标，不是学习者已经具备的能力。

| 级别 | 知识点 | 先理解到什么程度 | 源码入口或验证位置 |
| --- | --- | --- | --- |
| P0 | Python 函数、类、类型注解 | 能读参数、返回值与调用关系，修改小函数 | 从 `app/routers/console.py` 实际用法开始 |
| P0 | FastAPI 路由与参数校验 | 将 HTTP 方法和 URL 对应到处理函数，知道错误参数在哪里被拒绝 | `app/_app.py`、`app/routers/__init__.py`、`app/routers/console.py` |
| P0 | async/await 与异步迭代 | 用 Promise 类比等待，区分异步等待与 CPU 工作，理解逐段产出 | `post_console_chat`、`event_generator`、`TaskTracker` |
| P0 | SSE 与前端状态 | 区分连接、内容增量、错误、任务结束；从实际事件推导 UI 状态 | `console.py`、`task_tracker.py`，前端具体消费函数待追踪 |
| P0 | 模型消息与工具调用 | 模型提出调用，程序执行，结果再参与模型处理 | `agents/react_agent.py`；AgentScope 依赖边界需一起核对 |
| P0 | 会话保存与 SQLite 基础 | 查到保存位置，区分页面状态、会话状态和持久历史 | `app/chats/session.py`、`agents/context/scroll/history.py` |
| P1 | 取消、超时、异常和资源释放 | 解释关页面、停止、超时的区别，跟踪清理路径 | `app/routers/console.py`、`app/task_tracker.py`，真实模型与工具实验 |
| P1 | 上下文与记忆 | 模型本次看到的内容不等于所有保存信息 | `agents/context/scroll/`、`website/public/docs/context.en.md`、`memory.en.md` |
| P1 | 测试与运行追踪 | 用可控样本检查行为，串起同一次任务日志和事件 | `tests/`；具体测试按学习单元选取 |
| P2 | MCP | 理解统一工具协议与直接函数工具的区别；有余力做小实验 | `app/mcp/`、`app/routers/mcp.py` 及对应文档 |
| P2 | 复杂长期记忆、多 Agent、桌面打包 | 能说清边界，暂不追求实现细节 | 按后续目标再展开 |
