# 用 DeepTutor 在公司和家里接着学

更新日期：2026-10-30，Asia/Shanghai。

QwenPaw 继续作为学习对象；DeepTutor 是辅助理解和提问的工具，不新增一条学习大型平台的必修路线。

## 日常操作

- 开始：`D:\DeepTutor\继续学习.cmd`。
- 离开前：等任务结束，点击 `D:\DeepTutor\结束学习并同步.cmd`，看到上传和读回校验成功再关电脑。
- 两台电脑轮流使用。同步冲突时保留现场，不强制覆盖。

工具、家庭安装步骤、同步边界和故障处理见 [同步工具说明](../../tools/deeptutor-sync/README.md)。本机版本也保存在 `D:\DeepTutor\sync-kit\README.md`。

## 第一次回家必须带的东西

通过 U 盘等独立方式带上公司电脑的 `D:\DeepTutor\sync-local\sync.key`，在家庭初始化时本地导入。不要上传到 Git 或发给 AI；没有它就不能解密快照。

家里从 QwenPaw 的 main 拉取工具和文档，按说明安装相同版本 DeepTutor，安装位置同为 `D:\DeepTutor`。快照由工具从独立的 `deeptutor-sync` 分支读取，不要把该分支合并进 main。

公开仓库不存在私密分支；此方案上传的是加密快照。模型 API Key 仍在两台电脑各自本地配置。
